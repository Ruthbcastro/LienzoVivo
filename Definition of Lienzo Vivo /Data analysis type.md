
## Determination of Data Analysis Type

For this project, a mixed-methods approach will be used as follows:

### Qualitative Analysis
Following User-Centered Design (UCD), qualitative analysis will be used to understand user needs, frustrations, and behaviors. This will help create profiles, scenarios, and prototypes that reflect how users actually interact with the app. Research will be conducted to capture users’ opinions and frustrations regarding art applications that use augmented reality.

### Quantitative Analysis
Quantitative analysis will be used to measure user satisfaction with the prototypes. This will help validate design decisions and changes. Surveys will be conducted alongside the use of metrics to gather data.
